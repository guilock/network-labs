## `01` / SOBRE
 
Este repositório reúne os laboratórios práticos que faço enquanto estudo redes. A maioria parte de atividades do curso de **conceitos básicos de redes** da Cisco Networking Academy, feitas no **Cisco Packet Tracer**.
 
Meu objetivo é registrar não só o que funcionou, mas **o que eu fiz, o que aprendi e onde errei**, de um jeito que qualquer pessoa consiga ler rápido.

## `03` / COMO CADA LAB É DOCUMENTADO
 
Cada laboratório fica em uma pasta própria, com dois arquivos principais:
 
| Arquivo | O que tem |
|:---|:---|
| `README.md` | Resumo rápido, topologia, o que eu fiz, o que aprendi e os problemas encontrados |
| `enunciado-da-atividade.md` | Resumo, com minhas palavras, do que a atividade pedia e do nível dela |
 
Estrutura do repositório:
 
```bash
network-labs/
├── README.md
└── 01-rede-domestica/
    ├── README.md
    ├── enunciado-da-atividade.md
    └── Topologia-Fisica.png
```
 
> Os textos originais e os arquivos de atividade do curso são material da Cisco e não são publicados aqui. As explicações, os prints e as conclusões são minhas.
